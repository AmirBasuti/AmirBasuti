# Amir Basuti

**Research & software.**

I work on machine learning and build software around it.

I'm an MSc student in Computer Science at the University of Tehran. My research explores time-series representations, model evaluation, and learning from movement and health data. Alongside research, I work on backend services, data integrations, and developer tools.

### Selected work

- **[Research Notebook](https://github.com/AmirBasuti/research-notebook)** — A Python CLI for append-only research records, integrity checks, snapshots, and scoped local Git checkpoints.
- **[SHL 2026: Frozen Model Fusion](https://github.com/AmirBasuti/shl2026-frozen-model-fusion)** — A paper companion with the author manuscript and a tested reference for fixed probability fusion.
- **[Research & Engineering Portfolio](https://amirbasuti.github.io/)** — Project stories, interactive explanations, and engineering work, with the [source on GitHub](https://github.com/AmirBasuti/amirbasuti.github.io).

I was part of UT-IR, the first-place team in the Sussex–Huawei Locomotion Challenge 2026.

Python and PyTorch for research; Java/Spring and Python/FastAPI for backend work. I also build web interfaces with React and TypeScript.
